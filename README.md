# 경로당별 12회차 수업일지 자동화 웹앱

5개 이상 경로당의 1~12회차 수업일지(경로당 이름, 날짜, 회차, 수업 내용)를 PC와 스마트폰에서 실시간 연동하여 기록·관리하는 웹 애플리케이션입니다.

## 주요 기능
- **경로당별 12회차 수업일지 관리**: 궁말경로당, 센텀 퍼스트, 더포레스트힐 심화반, 더포레스트힐, 부천 원미 노인복지관 및 새 경로당 무제한 추가/수정/삭제
- **1~12회차 날짜 자동 채우기**: 1회차 시작일 기준 매주 1회(+7일) 또는 주 2회(월·수) 날짜 자동 계산
- **스마트폰·PC 실시간 클라우드 연동**: 스마트폰에서 입력한 수업 내용이 PC 화면에 실시간 자동 동기화
- **엑셀(CSV) 다운로드 및 A4 인쇄/PDF 저장 지원**
- **모바일 홈 화면 바로가기 앱(PWA) 지원**
